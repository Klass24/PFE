# Place image files used by the chart here

Add the following files to this folder before installing the chart if you want Grafana branding replaced:

- `grafana_logo.png` — full logo to replace `grafana_logo.png` in Grafana public images
- `grafana_icon.png` — small icon (favicon) to replace Grafana icon

Also you can add frontend images used by the app in `frontend/public/images/`:

- `fleetcontrol-logo.png` — header / full logo
- `fleetcontrol-sidebar.png` — small logo used in the sidebar
